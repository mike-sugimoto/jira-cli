# 初期要件メモ（jira-cli）

## 1. 目的
JIRA MCP が使えない環境で、Claude Code から JIRA チケットの取得・検索・一覧表示ができる CLI アプリを作る。

## 2. 制約・要件
- 言語は C#。Windows / Linux で動作すること。
- アーキテクチャ
  - .NET 標準の Dependency Injection を使う。
  - TDD 優先で開発する。
  - 機能を Interface ベースの注入可能なサービスに分解し、テストしやすくする。
  - 最初にアーキテクチャレベルで分解し、レビューを行う。
- JIRA へのアクセスは読み取り専用。書き込みは禁止。
- 認証
  - 個人のログイン権限で JIRA にアクセスする。
  - または、特定プロジェクトだけにアクセスを限定できるトークンなどを指定できるようにする。
- 開発は BMAD メソッドで進める。
- コマンドの実行内容と結果を作業ログとして随時蓄積する。
- 将来 Confluence にもアクセスできるよう、共通化できる処理はモジュール化を意識する。
